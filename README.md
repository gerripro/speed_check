# Speed Check

Консольный скрипт на Python для замера скорости скачивания с указанного HTTP(S)-адреса.
Выполняет **10 последовательных GET-запросов**, каждый раз полностью читая тело ответа.

## Запуск

Нужен Python **3.10 или новее**. Сторонние библиотеки не требуются.

```bash
git clone https://github.com/gerripro/speed_check.git
cd speed_check
python speed_check.py "https://example.com/large-image.jpg"
```

Замените пример на прямую ссылку на существующий файл, желательно размером несколько мегабайт.
На macOS/Linux при необходимости используйте команду `python3`, на Windows — `py`.

Необязательный тайм-аут (по умолчанию 30 секунд):

```bash
python speed_check.py "https://example.com/large-image.jpg" --timeout 60
python speed_check.py --help
```

Тайм-аут применяется к блокирующим операциям сокета, а не ко всему замеру.

## Результат и единицы

Скрипт выводит время и размер каждого ответа, затем:

- среднее время запроса в секундах: сумма длительностей / 10;
- общий объём скачанных тел ответов в байтах и MB (1 MB = 1 000 000 байт);
- скорость в **Mbps (Мбит/с)**: общий объём в байтах × 8 / сумма длительностей / 1 000 000.

Время измеряется через `time.perf_counter()`: от начала открытия соединения до полного
чтения ответа. Включает установку соединения, ожидание сервера и переходы по HTTP-редиректам,
но не вывод результатов в консоль. Объём учитывает тела конечных ответов, без HTTP-заголовков
и сетевых накладных расходов. Скорость рассчитывается по общим данным, а не как среднее
арифметическое скоростей отдельных запросов.

Файл читается порциями по 64 KiB и не сохраняется на диск. Запрашивается ответ без сжатия
(`Accept-Encoding: identity`); если сервер игнорирует заголовок, считаются фактически
прочитанные байты. Заголовок `Cache-Control: no-cache` просит сервер перепроверить кэш,
но не гарантирует его отсутствие.

Это скорость загрузки с конкретного сервера, зависящая также от его нагрузки и задержек,
а не гарантированная максимальная скорость интернет-канала. Один файл скачивается 10 раз:
например, файл 10 MB расходует примерно 100 MB трафика.

## Ошибки

Некорректный URL или тайм-аут: код завершения 2.
Сетевая ошибка, HTTP-ошибка или обрыв ответа: сообщение в stderr и код 1,
без итоговой статистики неполного замера. Автоматических повторов нет.
Успех: код 0. Прерывание Ctrl+C: код 130.

## Проверка

```bash
python -m unittest -v
```

Тесты используют локальный HTTP-сервер: внешний интернет не нужен.
